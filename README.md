# NexusRule AI — Symbolic Tech Knowledge Engine

A deterministic, zero-NLP, zero-RAG symbolic document question-answering web application built with separated HTML, CSS, and JavaScript files.

## Included Files
- `index.html` — Semantic page structure and interactive UI layout
- `styles.css` — Deep-navy and electric-cyan/amber responsive stylesheet
- `app.js` — Multi-format document adapters (`.pdf`, `.docx`, `.xlsx`, `.csv`, `.json`, `.xml`, `.html`, `.txt`), frame/triple Knowledge Base, forward-chaining production rules, and BFS graph search

## How to Run
- **Locally on Phone or PC:** Extract the ZIP archive and open `index.html` in Chrome or any modern browser.
- **Deploy Online:** Upload the ZIP directly to Netlify Drop (`https://app.netlify.com/drop`) or push the three files to GitHub Pages.
